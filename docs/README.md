# Anything Else Plus — Website

A warm, professional single-page website for Montrell Fuller's full-service contracting company serving Frierson, Shreveport, and all of northwest Louisiana.

## 📄 File
- **`index.html`** — The complete website (single file, no build tools needed)

## 🚀 How to Use

### To Add Photos
Open `index.html` in any text editor and look for the gallery sections:

**General Work Gallery (Slots 1–10):**
Search for `Project Photo 1` through `Project Photo 10`.

**Specialty Gallery (Slots 11–14):**
- Slot 11: Countertop Resurfacing
- Slot 12: Epoxy Floors
- Slot 13: Industrial Epoxy Coatings
- Slot 14: Walk-In Shower Installations

To add a real image, replace each gallery card's inner HTML. Example:
```html
<div class="gallery-card has-image" data-slot="1">
  <img src="your-photo.jpg" alt="Description" style="width:100%;height:100%;object-fit:cover;" />
  <div class="label">Your Project Name</div>
</div>
```

### To Edit the Bio
Search for `hero-bio` — Montrell's personal message is right there for you to tweak.

### To Customize
- **Colors**: The gold accent is `#b8860b`. Search and replace to change it.
- **Contact info**: Phone, email, and address are listed in multiple spots — search for `(318) 272-2242`, `aecplus@yahoo.com`, and `257 Fuller Ln` to update them.

## 🌐 Hosting
Open `index.html` in any browser to see it locally. To put it online:
- **GitHub Pages** (free): Push the file to a GitHub repo, enable Pages in Settings
- **Any web host**: Just upload `index.html`
